# Facebook Automation Suite

Official Windows installer releases and the optional update channel for Facebook Automation Suite.

## Download

Use the latest GitHub Release to download the Windows installer.

The installer includes the required browser runtime. End users do not need to install Python, Playwright, Chromium, or separate Python packages.

## Verification

The SHA-256 checksum for the current installer is published in `latest.json`.

## Important

The installer is currently unsigned. Windows SmartScreen may display an unknown-publisher warning until an Authenticode code-signing certificate is added.
